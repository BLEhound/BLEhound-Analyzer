# Welcome-page sidebar (BLEhound branding)

With `BLEHOUND_BRANDING=ON` these files replace Wireshark's `resources/json`
sidebar content:

- `slides.json`: colors and slide-type config only (no slides).
- `slides_custom.json`: the BLEhound slides, English with `*_i18n` Chinese.
- `learn_card.json`: the Learn card links and buttons.
- `banners/`: 1020x390 slide images, generated by `make-banners.py` from `src/`.

Add a photo: put it in `src/`, add a line to `BANNERS` in `make-banners.py`,
run the script, add a slide to `slides_custom.json`, rebuild.
